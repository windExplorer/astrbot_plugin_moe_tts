# 萌萌语音 · 设计说明

> 新插件，独立于旧 `astrbot_plugin_cosyvoice` 重写。服务端从「CosyVoice3 单服务」升级为
> **TaskHub 中转站 / tts_serve 网关**，主力模型 Qwen3-TTS-0.6B（极速克隆，无需参考文本），
> 保留 CosyVoice3 回退。目标和取舍记录于此，供后续维护直接阅读。

## 一、定位与拓扑

```
AstrBot  ──HTTP──▶  TaskHub 中转站(:9000)  ──▶  tts_serve 网关  ──▶  Qwen3-TTS（或 CosyVoice3）
   ↑                     │
   │                     └─ 队列调度（max_concurrent=1，TTS/绘图共享）、裸 PCM 返回
   └── 萌萌语音插件（本仓库）
        └─ 可选直连 tts_serve 网关(:50001) → ASR / 后端切换 / 显存管理 / 音色管理 API
```

- 默认连接 **TaskHub 中转站**（用户主力场景）：只暴露合成、音色列表、健康检查。
- 也可直连 **tts_serve 网关**：额外开放 ASR、后端切换、显存管理、音色增删改。
- **多服务端可配置，但同时只启用一个**（单选）。切换即换路由，不做权重分流（旧插件的按权重分流删除）。

## 二、服务端 HTTP 契约（实测，勿凭文档猜）

### TaskHub 中转站（默认）
- `GET /` → `{status, sample_rate, ...}`：采样率唯一来源（**不在响应头**）。
- `POST /inference_zero_shot`：`multipart/form-data`，字段 `tts_text`(必填)、`prompt_text`、`prompt_wav_path`（推荐）、`prompt_wav`（上传）。**无** fast_clone / 生成参数。
- 响应：裸 int16 PCM（24kHz mono，无 WAV 头），`application/octet-stream`，唯一自定义头 `X-Queue-Position`。
- 状态码：`200` 成功；`400` 参数；`429` 排队超时（可退避重试）；`504` 推理超时（可退避重试）；`500` 上游失联/空音频（不重试，进冷却）。
- `GET /voices` → `{voices_dir, files, texts}`（TaskHub 自己的映射）。
- **无鉴权**。全局并发 1，队列 `queue_wait=120 + infer_timeout=120`，故插件读超时默认 **250s**。

### tts_serve 网关（可选直连）
- `GET /` → `{status, backend, model_loaded, sample_rate, switching}`。
- `POST /inference_zero_shot`：同 TaskHub，额外支持 `fast_clone`、`max_new_tokens`/`temperature`/`top_k`/`top_p`/`repetition_penalty`/`subtalker_*`。响应头 `X-Generation-Time`、`X-Sample-Rate`。
- 管理：`GET /api/status`、`POST /api/switch_backend`、`POST /api/vram/unload|load`、`GET|PUT /api/config`、`GET /api/voices` 及增删改、`GET /api/voices/{name}/audio`、`POST /api/asr`。
- **无鉴权**。后端 qwen3 / cosyvoice3 由网关启停 worker 切换。

## 三、功能取舍（相对旧 cosyvoice 插件）

### 保留并增强
| 能力 | 说明 |
| --- | --- |
| 会话级语音开关 / 音色 / 发送方式 | `/语音开`、`/语音关`、`/语音音色` 等，按会话持久（重启不丢）。WebUI 会话页同源管理。 |
| 自动语音 + 关键词触发 | `auto_tts`、`trigger_keywords`、`text_keywords`（本条只发文字）。 |
| LLM 工具 | `text_to_speech`、`set_voice_mode`、`set_voice`、`list_voices`，**新增 `transcribe_audio`（ASR，直连网关时）**。 |
| 文本绝不丢上下文 | `both` 模式原文留结果链；`voice_only` 由 AstrBot 单独存 `completion_text`。 |
| 括号不朗读 / 分段策略 / 换行分段 | 沿用成熟规则，纯函数实现，带单测。 |
| 副语言标记 | `[breath]`/`[laughter]` 等，按音色 `markup` 开关注入。 |
| 翻译合成 | 通用翻译适配器（保留，配置存插件自有 JSON）。 |
| 任务日志 + 服务端健康 + 队列位置 | WebUI 时间线、失败原因、排队位置提示。 |
| 失败降级 + 冷却 + 退避重试 | 429/504 退避，500 进冷却，冷却内只发文字。 |
| WebUI 内嵌页 | 7 页：总览 / 音色 / 会话 / 合成实验室 / 服务端 / 日志 / 配置。 |

### 增强（新插件特有）
- **多服务端单选**：WebUI 服务端页一键切换 TaskHub / tts_serve，列表可存多个地址，同时只启用一个。
- **采样率自动探测**：首次合成前读 `GET /`，避免音调失真。
- **队列感知**：解析 `X-Queue-Position`，WebUI 实时显示「前面还有 N 个任务」，超阈值直接回退文字。
- **直连网关专属能力**：ASR 转写（WebUI 上传音频 + LLM 工具）、后端切换、显存卸载/加载、服务端音色 CRUD。
- **合成实验室**：WebUI 内直接输入文本试听，实时波形、生成耗时、下载 WAV。
- **WebUI 栈升级**：Vue 3.5 + Vite + TypeScript + Tailwind CSS v4 + lucide-vue-next，动效 + 完整移动端适配（底部导航 / 抽屉 / 安全区）。

### 删除（不再实现）
- `deploy/` CosyVoice 服务端部署脚本（服务端已独立为 tts_serve 项目）。
- Gradio WebUI 兼容说明、instruct2 调用（中转站需 `instruct_text`，插件只走 zero_shot）。
- 按权重分流 / 多节点并发（旧 servers 多节点）→ 改为单选。
- 文件服务 URL 发送（依赖 monkey-patch 适配器，脆弱）→ 常规 `Record` 发送；若平台不支持语音自动回退文字。
- i18n 多语言（工作区红线：插件页只写简体中文，不建 `.astrbot-plugin/i18n/`）。

## 四、模块结构

```
main.py           Star 入口：钩子 + 指令 + LLM 工具 + 热重载 sibling 模块
server.py         服务端适配：ServerSpec / TaskHubAdapter / TtsServeAdapter / TTSRouter（单选+熔断+退避）
tts_engine.py     引擎：音色解析、文本分段、标记注入、合成编排、PCM→WAV
textutil.py       纯函数：文本净化、分段、括号剔除、语种检测、标记
store.py          持久化：会话开关/音色/日志/默认音色/音色库（JSON，写在 data_dir）
translator.py     翻译适配器（通用 HTTP，配置存插件自有 JSON）
webapi.py         WebUI 后端 API（ctx.register_web_api）
skills/           AstrBot Skill：语义触发语音开关/朗读
webui-src/        Vue3+Vite+TS+Tailwind4 前端源码
pages/moe-tts/    构建产物（入库，zip 依赖）
build_webui.ps1   注入版本号 + vite build
build_zip.ps1     显式文件清单打包（撞版检测，保留旧包）
tests/            纯函数自检
```

## 五、硬约束（不可回退）

1. 文本绝不丢失：不修改 `resp.completion_text`；`both` 原文留链，`voice_only` 依赖 AstrBot 独立存历史。
2. 防重复：指令 / LLM 工具发语音后设 `suppress`；结果链含 `Record` 跳过；message_id 级去重；主动推送文本 60s 回环拦截。
3. 失败降级：任何服务端异常都不阻断文字消息；冷却期内直接发文字。
4. 新增顶层 `.py` 必须同步 `main.py` 热重载列表与 `build_zip.ps1` 的 `$includeList`。
5. WebUI 禁止 i18n，界面文案一律简体中文。
