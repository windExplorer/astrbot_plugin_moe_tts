# 萌萌语音 · 语音模式技能

本技能让模型通过语义理解（而非写死关键词）帮用户管理语音。所有操作都通过调用工具完成。

## 何时使用

- 用户说「以后用语音跟我交流」「开始语音聊天」「我想听你说」→ 开启语音模式。
- 用户说「别用语音了」「改回文字」「用文字回复」→ 关闭语音模式（本条只发文字）。
- 用户说「换成小明的声音」「用日语音色」「换个性别的声音」→ 切换音色。
- 用户说「你有哪些声音」「能用什么音色」→ 列出音色。
- 用户给出一段具体文本并说「念出来」「朗读这段」→ 临时朗读一次。
- 用户提供音频/说「把这段语音转成文字」→ 语音识别（需服务端支持）。

## 工具选择规则

| 用户意图 | 调用工具 | 参数 |
| --- | --- | --- |
| 长期开/关语音 | `set_voice_mode` | `enable`: true / false |
| 切换音色 | `set_voice` | `voice`: 音色名（不确定时先 `list_voices`） |
| 列出音色 | `list_voices` | 无 |
| 临时朗读指定文本 | `text_to_speech` | `text`: 要念的原文；`voice` 可选 |
| 语音识别 | `transcribe_audio` | `audio_base64`: 音频 base64；`language` 可选 |

## 注意事项

- 用户没有给出具体文本时，不要调 `text_to_speech`；先反问要念什么。
- 用户只是闲聊提到「语音」两个字（如「语音消息没收到」）不代表要切换模式，需结合上下文判断真实意图。
- 「本条用文字回复」是一次性的，不要因此关闭长期语音开关；用 `set_voice_mode(enable=false)` 只在用户明确要长期关闭时调用。
- 切换音色后无需额外朗读确认，工具会返回结果。
